# Content types

Reusable templates (future Jekyll/Astro layouts), not hand-built one-off pages.

| Type | Use |
|------|-----|
| Long-form essay | Philosophical / conceptual writing |
| Research article | Structured investigation, methods, interpretation |
| Technical article | Experiments, explanations, analysis |
| Research thread | Sequential observations and developing argument |
| Field note | Short exploratory record |
| Concept page | Definition, distinctions, relationships |
| Framework page | Developed structure; versions; limits |
| Project page | Independent project + repo links |
| Reading note | Literature, synthesis |
| Research log | Chronological intellectual development |
