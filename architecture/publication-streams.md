# Publication streams

Requirement: **multiple independently navigable streams**, one visual and structural design system.

| Stream | Typical content |
|--------|-----------------|
| HAI Research Journal | Longitudinal observations, interaction notes |
| Philosophy & Cognition | Phenomenology, mind, consciousness explorations |
| Technical Investigations | Long-context, prompts, evaluation, semantics |
| Conceptual Frameworks | Named structures, versions, limitations |
| Research Threads & Field Notes | Short records, developing arguments |
| Projects & Experiments | Implementations; outbound GitHub links |

## Per-stream needs

- Landing page and short description  
- Content index  
- Tags / categories  
- Chronological browse where appropriate  
- Links to related concepts and frameworks  

## Metadata (planned)

Support via front matter: `streams`, `domains`, `concepts`, `type`, `status`, `epistemic_level`, `related`, external publication URLs.

One article may appear in multiple conceptual categories.
