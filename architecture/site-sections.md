# Site sections (information architecture)

Intellectual navigation first — not a single chronological blog.

## Top-level sections (hypothesis for discussion)

| Section | Responsibility |
|---------|----------------|
| **Orientation** | Central inquiry, positioning, scope, research approach |
| **Domains** | Broad areas (HAI, phenomenology, cognition, …) |
| **Concepts** | Terms, definitions, relationships |
| **Methods** | Approaches to inquiry |
| **Frameworks** | Structures, versions, limits |
| **Research journal** | Chronological observations, threads |
| **Technical investigations** | Long-context, prompts, evaluation, prototypes |
| **Projects** | Independent work; links to GitHub repos |
| **Publications** | Essays, Substack, selected external writing |

Future sections should fit without restructuring the core model.
