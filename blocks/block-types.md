# Block types

Intellectual content is stored as **reusable blocks**, not repeated biography variants. Each block can be understood, revised, connected, published or challenged on its own.

| Block type | Function | Example |
|------------|----------|---------|
| Domain block | Area of inquiry | Human–AI interaction |
| Concept block | Explains an idea | Semantic drift |
| Method block | How investigation runs | First-person participatory inquiry |
| Observation block | Something noticed | Loss of conversational continuity |
| Hypothesis block | Proposed interpretation | Context accumulation may affect perceived continuity |
| Framework block | Organizes multiple concepts | Longitudinal interaction analysis |
| Reflection block | Cognitive development over time | Changing mental models of AI |
| Technical block | Implementation / experiment | Structured prompt experiments |
| Publication block | Developed outward-facing piece | Substack essay (linked, not duplicated) |

## Modular depth on concepts

A single concept may include some or all of:

1. Plain-language interpretation  
2. Philosophical interpretation  
3. Cognitive-scientific connections  
4. HAI application  
5. Technical interpretation  
6. Methodological approach  
7. Related concepts  
8. Critical examination  
9. Practical example  
10. Open questions  

Not every module is required for every concept — depth is optional per page.
