# Concept exploration protocol

Reusable workflow for developing **one concept** across levels of understanding (archive authoring aid).

For each concept supplied (notes, fragments, terminology):

1. **Plain-language interpretation** — minimal jargon  
2. **Philosophical interpretation** — epistemological / phenomenological / ontological where relevant  
3. **Cognitive-scientific interpretation** — connect to established ideas without inventing consensus  
4. **Human–AI interaction interpretation** — sustained LLM dialogue context  
5. **Technical interpretation** — observable behavior, variables, implementation angles  
6. **Methodological interpretation** — how it could be investigated  
7. **Conceptual relationships** — related terms, overlaps, distinctions  
8. **Critical examination** — assumptions, ambiguities, alternatives  
9. **Practical example** — concrete extended-interaction example  
10. **Internalization checks** — questions that test independent explanation and critique  

Requirements when using this protocol:

- Preserve original terminology when distinctions matter  
- Do not treat hypotheses as established facts  
- Separate observations, interpretations, hypotheses and findings  
- Do not collapse philosophical traditions into one voice  
- Mark metaphor vs established technical term  

Objective: conceptual precision and interdisciplinary fluency, not polished biography.
